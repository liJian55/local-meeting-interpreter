本地会议同传 - Windows 64位绿色版

使用方法
1. 将整个 MeetingInterpreter 文件夹解压到本地磁盘，不要在 ZIP 内直接运行。
   若安全软件拦截当前目录，请将整个文件夹移到桌面等常用目录，或信任该文件夹。
2. 双击 Interpreter.exe。无需安装 Python、模型或其他工具，无需联网。
3. 首次使用在界面选择自己的音频来源；飞书会议默认跟随 Windows 默认播放设备。
4. 勾选翻译方向，点击“开始同传”。停止同传不会关闭软件。

说明
- 所有音频识别和翻译都在本机进行，无需 API Key，不上传会议音频。
- 当前为实时字幕版，不包含译文语音朗读。
- 桌面 Meeting Interpreter 快捷方式会在启动时自动更新到当前目录。
- 首次启动若出现 SmartScreen“发布者未知”，是自编译程序没有数字签名所致；确认文件来源后可选择仍要运行。
- 若更换耳机或扬声器，请重新选择对应音频来源。
- 项目源代码见随包 src 文件夹。
